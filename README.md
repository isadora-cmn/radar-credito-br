# Radar do Crédito Brasileiro

Pipeline de dados de ponta a ponta sobre crédito no Brasil, com dados públicos do Banco Central.

## Pergunta guia

Quando os juros sobem, a inadimplência sobe? Depois de quantos meses? Pessoas físicas e empresas reagem igual? Dá para prever os próximos meses?

## Plano

- Semana 1: ingestão dos dados do Banco Central e primeiras consultas em SQL
- Semana 2: camadas bronze, silver e gold, testes de qualidade e automação
- Semana 3: análise, previsão e dashboard em Streamlit
